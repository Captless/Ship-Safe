# V1.2.2 — Discovery Progress Fix + Scan Complete Checkpoint

## Status

PLANNED

## Objective

Fix two UX/lifecycle issues in the current Ship Safe scanner:

1. The progress tracker can appear stuck or stale at
   "Discovering files" while the backend is actually processing the
   extracted project.

2. When a scan finishes, the frontend immediately displays the full
   findings report. Instead, show a simple "Scan Complete" checkpoint
   containing the scan summary and a "Review Report" button before
   revealing the full results.

This is a focused incremental improvement.

Do NOT redesign the scanner.
Do NOT redesign the V1.2 beginner-friendly report.
Do NOT introduce AI APIs.
Do NOT introduce new infrastructure.

==================================================
BUG 1 — DISCOVERY PROGRESS GETS STUCK
==================================================

CURRENT PROBLEM

The backend currently performs:

    _apply_state(
        state,
        phase="discovering",
        message="Discovering project files"
    )

followed by:

    files = list(iter_text_files(workspace))

The existing iter_text_files() is a generator, but the backend
consumes the entire generator into a list before updating:

    files_discovered=len(files)

Therefore the frontend can remain on:

    Discovering files

with no meaningful changing information while the backend is
actually reading the project.

This is the primary issue to fix.

==================================================
DISCOVERY PROGRESS REQUIREMENT
==================================================

Discovery progress must be real.

Do NOT invent a percentage.

Do NOT estimate discovery progress based on elapsed time.

Do NOT pretend to know the total number of discoverable files before
discovery has completed.

Instead, expose an accurate incremental counter.

Example:

    Discovering files

    We're looking through your project structure.

    347 files discovered

Then:

    1,204 files discovered

Then:

    1,821 files discovered

When discovery completes:

    1,821 files discovered
